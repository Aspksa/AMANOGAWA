# AMANOGAWA

天の川 — Млечный Путь.

## Запуск

Дважды кликните **`AMANOGAWA.BAT`** (Windows).

- Если установлен Python, поднимется локальный сервер и сайт откроется по адресу http://localhost:8000/. Закройте окно, чтобы остановить сервер.
- Если Python нет, `index.html` откроется прямо в браузере.

## Структура

- `index.html` — страница (пока пустая оболочка)
- `css/style.css` — стили, адаптивные под любой размер экрана
- `js/main.js` — звёздное небо и мобильное меню
