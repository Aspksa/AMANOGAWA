# AMANOGAWA

天の川 — Млечный Путь.

## Запуск

Дважды кликните **`AMANOGAWA.BAT`** (Windows).

1. При первом запуске создаётся `.venv` и ставятся RAG-Anything и зависимости (это долго: MinerU тянет PyTorch, нужно 10+ минут и несколько ГБ).
2. Сайт открывается на http://localhost:8000/. Если порт занят, сервер выбирает свободный и открывает правильный адрес; он также виден в окне запуска. Откройте **Настройки** (шестерёнка внизу меню), вставьте ключ Cloud.ru, нажмите «Проверить ключ и загрузить модели», выберите модели и «Сохранить».

## Разделы

Меню иконками слева (на телефоне — снизу):

- **Главная** — звёздное небо и аватар. Клик по аватару открывает **чат** с базой знаний: ответ печатается по мере генерации, под ответом — файлы-источники, уточняющие вопросы учитывают предыдущие (кнопка «Новый диалог» сбрасывает память). На остальных страницах чат открывается маленьким аватаром в правом нижнем углу.
- **Документы** — загрузка (перетаскиванием), статус индексации, удаление из базы. Список хранится в базе и не пропадает после перезапуска.
- **Граф знаний** — сущности и связи, которые RAG-Anything извлёк из документов: колесо — масштаб, перетаскивание — сдвиг, клик по узлу — описание и связи.
- **Настройки** — ключ, адрес API, модели (ответы, эмбеддинги, зрение для картинок в PDF), режим поиска, top_k, память диалога, язык описаний графа, парсер. Всё сохраняется в `.env`.

Если Python 3.10+ не найден (ни в PATH, ни в реестре, ни в обычных папках), BAT сам скачивает официальный Python 3.12 в папку проекта `.python` (около 20 МБ, без установщика и прав администратора).

Аватар на главной можно перетаскивать мышью или пальцем, двойной клик возвращает его на место.

Окно BAT не закрывается само: если что-то пошло не так, ошибка останется на экране. Запускайте BAT из распакованной папки, а не прямо из ZIP-архива.

Если установка зависимостей не удалась, окно сохраняет текст ошибки. Повторный запуск проверяет окружение и повторяет установку при необходимости. Ключ и данные базы остаются в `.env` и `data/`. После обновления исходников RAG-Anything установка также проверяется заново.

Во время индексации или генерации ответа изменение настроек временно блокируется: дождитесь окончания операции и повторите сохранение. Это защищает открытые хранилища от закрытия посреди работы.

## База знаний: RAG-Anything + Cloud.ru

- [RAG-Anything](https://github.com/HKUDS/RAG-Anything) (MIT) лежит целиком в `vendor/RAG-Anything`, версия записана в `vendor/RAG-Anything.VERSION`.
- Модели — Cloud.ru Foundation Models через OpenAI-совместимый API (`https://foundation-models.api.cloud.ru/v1`).
- Ключ хранится только в `.env` на вашем компьютере; `.env` в `.gitignore` и в git не попадает.
- Модели выбираются в «Настройках» из списка, который отдаёт Cloud.ru по вашему ключу.
- У каждой модели эмбеддингов своя база (`data/rag_storage/<модель>`): после смены модели документы нужно загрузить заново.
- `.txt` и `.md` индексируются сразу; PDF, Office и картинки разбирает парсер MinerU (на Python 3.14 MinerU не ставится, там работают только текстовые файлы).
- Загруженные файлы и индекс хранятся в `data/` (тоже не попадает в git).

API сервера: `/api/status`, `/api/settings`, `/api/models`, `/api/upload`, `/api/documents`, `/api/query` (поток NDJSON), `/api/graph`. Документация — http://localhost:8000/api/docs. Сервер принимает запросы только с этого компьютера.

Запуск без BAT: `python -m pip install -r requirements.txt`, затем `python -m server`.

## Проверки

Для разработки: `python -m pip install -r requirements-test.txt`, затем `python -m pytest -q` и `node --test tests/test_stream.cjs`. Python берёт исходники RAG-Anything из `vendor/` через `pytest.ini`. Эти проверки работают без ключа Cloud.ru, MinerU, PyTorch и загрузки весов моделей; они не подтверждают доступность выбранной модели по вашему ключу.

GitHub Actions запускает эти проверки на Linux (Python 3.10 и 3.12) и Windows (Python 3.12), включая обнаружение Python через BAT. Установка и распознавание PDF парсером MinerU требуют отдельной проверки в рабочем окружении.

## Структура

- `index.html` — страница
- `css/style.css` — стили, адаптивные под любой размер экрана
- `js/main.js` — звёздное небо, меню и переключение разделов
- `js/chat.js`, `js/docs.js`, `js/graph.js`, `js/settings.js` — чат и разделы
- `img/` — аватар
- `server/` — сервер на FastAPI: отдаёт сайт и API базы знаний
- `vendor/RAG-Anything/` — исходный код RAG-Anything
